# مشروع السفروت (Manus Clone) 🚀

واجهة وكيل ذكي متطور مبني باستخدام LangChain و LangGraph مع دعم كامل للغة العربية وواجهة مستخدم احترافية.

## المميزات الرئيسية
- 🌐 **تصفح المواقع:** القدرة على زيارة المواقع والتفاعل معها.
- 💻 **تعديل الكود:** قراءة وكتابة الملفات وتنفيذ أوامر الشل.
- 🔌 **نظام الموصلات:** ربط وإدارة التطبيقات الخارجية.
- 📁 **رفع الملفات:** دعم رفع ومعالجة الملفات والصور.

## المتغيرات المطلوبة (Environment Variables)

لتشغيل المشروع، يجب إنشاء ملف `.env` في المجلد الرئيسي وإضافة المتغيرات التالية:

| المتغير | الوصف | الحالة |
| :--- | :--- | :--- |
| `OPENAI_API_KEY` | مفتاح API الخاص بـ OpenAI | **مطلوب** |
| `OPENAI_BASE_URL` | رابط الـ API (افتراضياً https://api.openai.com/v1) | اختياري |
| `PORT` | المنفذ الذي سيعمل عليه الخادم (افتراضياً 8080) | اختياري |
| `GEMINI_API_KEY` | مفتاح API الخاص بـ Gemini | اختياري |

## طريقة التشغيل

1. تثبيت التبعيات:
   ```bash
   pnpm install
   ```

2. تشغيل الخادم:
   ```bash
   npm start
   ```

3. افتح المتصفح على: `http://localhost:8080`
